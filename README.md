# 陈巧个人学术网站

双语个人学术主页，内容基于《陈巧长理简历.docx》和学院公开资料整理。

## 网站内容

- 个人简介与任职信息
- 中英双语研究方向
- 7 篇主要学术论文
- 10 篇工作论文
- 7 项科研项目
- 2 项教学改革项目
- 本科与硕士课程
- 7 项获奖荣誉
- 学术服务与联系方式
- PDF 与 Word 简历下载
- 明暗主题与手机适配

## 网站地址

- 正式网址：https://www.chenqiao.com.cn
- 管理入口：https://www.chenqiao.com.cn/assets/edit.html

## 本地预览

    node server.js

然后打开：

    http://127.0.0.1:4173

## 主要文件

- index.html：双语页面内容
- styles.css：页面视觉和响应式布局
- script.js：导航、主题切换、论文筛选和邮箱复制
- assets/Chen-Qiao-CV.pdf：新版 PDF 简历
- assets/Chen-Qiao-CV.docx：新版 Word 简历
- CNAME：自定义域名
- .github/workflows/pages.yml：GitHub Pages 自动部署
